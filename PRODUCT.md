# Product

## Register

product

## Users

Mac users converting and editing local files while working in Finder, with English or Arabic interfaces.
The primary workflow is drag, tap a modifier, and drop on a wheel option.

## Product Purpose

Transflo is a native macOS menu-bar utility for local file conversion, focused editing, and file actions.
It keeps originals safe and places results beside their sources.

## Brand Personality

Native, clear, responsive. Use the app's existing system typography, adaptive appearance, and accent preferences.

## Anti-references

Avoid unnecessary empty space, fixed-height settings pages, oversized controls, and decorative UI that interrupts file work.
Tangerine's functional controls are a reference for the requested enhancements, not a replacement visual identity.

## Design Principles

- Keep the drag workflow fast while giving deliberate control to editing operations.
- Show source facts, target meaning, validation, and result limits clearly.
- Fit short content naturally and scroll expanded controls within the available screen.
- Preserve originals and saved preferences across upgrades.
- Share preview and export processing so controls have consistent effects.

## Accessibility & Inclusion

Maintain the existing English/Arabic localization, right-to-left layout, VoiceOver labels, keyboard interaction,
adaptive light/dark appearance, and reduced-motion preferences. Haptics are optional and never the only feedback.
